# Social Account Connection Stats

**Status:** 🟢 Complete
**Branch:** `feature/social-account-stats`
**Date:** 2026-06-24

## Overview

When a creator successfully connects a social media account (TikTok, Instagram,
YouTube), the account is marked **Connected** and now surfaces richer verified
stats — followers, **total likes**, and **post count** — in addition to the
average views already shown. Stats appear both on the creator onboarding social
step and the settings → social accounts page.

## What changed

### Backend
- **Migration** `add_stats_to_social_accounts_table` — adds `total_likes`
  (unsignedBigInteger, nullable) and `post_count` (unsignedInteger, nullable)
  to `social_accounts`.
- **`SocialAccount` model** — `total_likes` and `post_count` added to `$fillable`.
- **`ConnectedAccount` DTO** — new `?int $totalLikes` and `?int $postCount`
  properties.
- **Providers** — each populates the new fields from the platform API (and stub):
  - **TikTok** — `likes_count` → total likes, `video_count` → post count
    (already requested in the `user/info` fields list).
  - **Instagram** — `media_count` → post count (Basic Display exposes no total
    likes, so `total_likes` is null).
  - **YouTube** — `videoCount` → post count (channel statistics has no total
    likes, so `total_likes` is null).
- **`SocialAccountService::connect()`** — persists `total_likes` / `post_count`
  on connect.
- **`SocialAccountsController`** (settings) — exposes the two new fields to the
  page. The onboarding controller already passes full models, so no change there.

### Frontend
- **`settings/social-accounts.tsx`** — renders likes (Heart) and posts
  (PlaySquare) chips alongside followers/avg views.
- **`onboarding/creator/social.tsx`** — connected accounts now show
  followers / likes / posts chips instead of a single follower line.

## Notes
- Total likes is only available from TikTok with the current OAuth scopes;
  Instagram and YouTube show followers + posts. The UI hides any stat that is
  null/zero so platforms degrade gracefully.
- Stats are captured at connect time and refreshed by the existing
  `SyncViewCountJob` / follower-sync flow.
