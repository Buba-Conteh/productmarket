# Connected Social Account Metrics on the Creator Profile

**Status:** 🟢 Complete
**Branch:** `feature/social-account-metrics-sync`
**Date:** 2026-09-22

## Overview

Connecting TikTok (or Instagram / YouTube) already marked an account as
**Connected** and captured its stats at that moment. This feature makes those
metrics *live*: they are re-queried from the platform on a schedule and on
demand, and every connected account — not just the ones a platform flags as
verified — now appears on the creator's public profile and media kit with the
full metric set.

## Problems this fixed

1. **Metrics were frozen at connect time.** `fetchAccountProfile()` was only ever
   called from `SocialAccountService::connect()`. Nothing re-queried account-level
   stats afterwards, so follower counts, likes and post counts never moved again.
   `PlatformProvider::fetchFollowerCount()` was implemented by all three providers
   but called from nowhere in the app.
2. **Instagram accounts were invisible on the profile.** `InstagramProvider` sets
   `verified: false` (Basic Display exposes no verification), and
   `CreatorProfileController` filtered `->where('verified', true)`. A creator could
   connect Instagram successfully and never see it on their profile.
3. **The profile dropped the richer stats** — `total_likes` and `post_count` were
   stored and shown in settings but never passed to the profile or media kit.
4. **No manual refresh** — a creator whose follower count had moved had no way to
   pull fresh numbers short of disconnecting and reconnecting.

## What changed

### Backend
- **`SocialAccountService::syncStats(SocialAccount): bool`** — refreshes the token
  if needed, re-queries the platform with the stored token, and persists handle,
  followers, likes, posts, avg views, engagement and `verified`. Returns `false`
  and logs `social_account_stats_sync_failed` when the platform can't be reached,
  leaving the last known numbers in place.
- **`SocialAccountService::preferFresh()`** — the live profile endpoints return `0`
  for metrics they don't expose (TikTok/IG/YouTube all return 0 for avg views and
  engagement rate). A zero never overwrites a known value, so a metric captured
  earlier isn't blanked by a later sync.
- **`SocialAccountService::findForUser()`** — looks up one connected account by
  platform slug for the refresh endpoint.
- **`SyncSocialAccountStatsJob`** — sweeps every connected account, or one account
  when given an id. Scheduled every `SOCIAL_STATS_SYNC_FREQUENCY_HOURS` (default
  12) at :30, inside the existing `social_oauth.sync.enabled` gate. Entry-level
  view counts remain `SyncAllLiveEntriesJob`'s job.
- **`SocialAccountController::refresh()`** + `POST creator/social/{platform}/refresh`
  (throttled 10/min) — on-demand refresh from settings. 404s for a platform the
  creator hasn't connected.
- **`CreatorProfileController`** — `show()` and `mediaKit()` now list every
  connected account and pass `total_likes`, `post_count`, `verified` and
  `last_synced_at` through.

### Frontend
- **`components/social/social-stat-chips.tsx`** — the compact chip row (followers /
  likes / posts / avg views / engagement / synced-at), used by settings and
  onboarding. Any metric a platform doesn't expose is omitted, not shown as zero.
- **`components/social/connected-account-row.tsx`** — the profile/media-kit row:
  platform, handle, a verified check when the platform confirmed the account, and
  the metric columns.
- **`lib/format.ts`** — `formatCompactNumber`, replacing four copies of the same
  `12500 -> "12.5K"` helper across these pages.
- **`settings/social-accounts.tsx`** — per-account **Refresh** button with a
  spinning state.
- **`profiles/creator/show.tsx`**, **`profiles/creator/media-kit.tsx`**,
  **`onboarding/creator/social.tsx`** — all render through the shared components.

## Notes
- Locally, providers run in stub mode (`VIEW_SYNC_STUB_MODE`), so connecting and
  refreshing return the stub figures (12.5K followers / 348K likes / 142 posts for
  TikTok) rather than live platform data.
- Total likes is only available from TikTok under the current OAuth scopes;
  Instagram and YouTube report followers and post count.
